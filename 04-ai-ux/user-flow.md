# AI-Native User Flow · Juno

_Module 4. Generated by `M4 - AI User Flow Architect.html`. Paste over `04-ai-ux/user-flow.md`._

## Entry point

**Signal type:** New message / transcript received

A new user transcript is received and automatically added to the Raw User Transcripts column.

**What they see instantly**

“Juno is analyzing new evidence…” status badge appears, with a subtle progress indicator.

## The flow

1. RAG retrieval over Strategy/Product context → evidence extraction from transcript → strategic alignment scoring → risk + confidence assessment
2. “Reading new transcript…” → “Retrieving relevant strategy context…” → “Cross-referencing product evidence…” → “Assessing alignment + confidence…”
3. Path A: New evidence: Transcript/feedback received → RAG retrieval + evidence extraction → strategic alignment analysis
Path B: Action requested: PM asks Juno to draft/update a PRD → PRD generation workflow → draft output
Path C: Low confidence / conflict: Insufficient or conflicting evidence → flag for PM review → human checkpoint

## AI moments

**Placement:** Inline & Embedded

Priority insight cards in the Insights column, each showing the user need, strategic alignment score, and supporting transcript citation.

Augmentation → Juno surfaces evidence-backed priorities and rationale so the PM can review, validate, and refine decisions instead of starting from a blank page.

## Fallbacks

**Kill switch**

“Override” button on every insight card → lets the PM accept, edit, or reject Juno’s recommendation before it is used in the PRD.

**Training signal**

Captured training signal · what gets logged back
e.g. “Manual demote → logged as ‘strategic-alignment correction’ → tightens future scoring.”

**Fail-safe**

If required strategy context or evidence is missing → Juno enters “cautious mode,” flags the gap, and withholds the alignment score until the PM reviews it.
