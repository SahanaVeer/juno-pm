## What "good" means

≥80% acceptance rate and ≤20% rejection/regeneration rate across production interactions

Active signals

Accept - user accepts Juno’s recommendation, insight, or PRD content without changes.
Edit - user modifies the generated output before using it.
Reject / Dismiss - user rejects an insight, recommendation, or generated content.
Regenerate - user asks Juno to generate an alternative.
Thumbs up / down - explicit quality feedback on an output.
Correction reason - optional structured reason for rejecting or editing an output (e.g., incorrect, missing context, wrong priority, not actionable).
Final usage - user copies, exports, or moves the generated PRD content into their workflow.

Passive signals

Edit distance - how much the user changes Juno's generated content.
Time to accept/edit/reject - indicates confidence or friction.
Regeneration frequency - repeated regeneration can signal low output quality.
Feature abandonment - user starts a workflow but exits before completion.
Repeat usage - whether users return to Juno and continue using the same workflow.
Downstream usage - whether generated PRD elements are subsequently used in the product workflow.

## Golden set

Version-controlled set of representative Juno inputs and expected outputs, covering core use cases, edge cases, failure modes, and previously detected errors; updated whenever new production failures are identified.

## Release gate

**Hard gates (auto-block):**

Any critical safety/PII violation; fabricated or missing evidence presented as fact; factual accuracy below the minimum threshold; or failure of required PRD schema/format.

**Soft gates (PM sign-off):**

Rubric score below target but above the hard-fail threshold; elevated edit/rejection/regeneration rates; minor evidence gaps; or recurring quality issues that do not create a critical risk. PM must document the rationale and mitigation before release.

**User-feedback layer (online):** cadence Continuous / real-time, with weekly trend review; owner Product Manager.
